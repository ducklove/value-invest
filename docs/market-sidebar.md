# 사이드바 시장 지표

2026-09-11: 기존 네이버 PC 지수·환율 페이지가 `stock.naver.com`으로
리다이렉트되어 HTML에서 값이 사라지는 문제를 수정했다.

- 국내 지수 3개는 네이버 `polling.finance.naver.com`의 국내 지수 JSON을 묶어 조회한다.
- 해외 지수 6개와 환율·달러지수 7개는 `api.stock.naver.com`의 JSON을 사용한다.
- 금·WTI 등 다른 공급 경로는 기존 수집기를 사용한다. 항목별 캐시는 60초다.
- 시세 기준 시각(`as_of`), 수집 시각(`fetched_at`), 거래 상태와 제공 지연 시간을 보존한다.
  휴장 시장의 마지막 시세 날짜를 수집 날짜로 대체하지 않는다.
- 수집 실패 시 이전 값을 `_stale`과 함께 반환하며, 성공 응답을 받으면 해제한다.
  사이드바는 이전 값에 `지연`을 붙이고 마우스를 올리면 기준 시각(KST)을 보여준다.
  서버 요청 실패·누락 응답에도 같은 표시를 적용한다.
- 60초마다, 백그라운드 탭에서 복귀할 때, 브라우저 뒤로가기로 복원될 때 갱신한다.
  HTTP 브라우저 캐시를 사용하지 않으며 동시에 진행하는 요청을 합친다.

실제 공급자의 지연 시세(예: 닛케이 15분, 달러지수 10분)는 수집 오류와 별개이며
마우스 설명에 제공 지연 시간으로 표시한다. 본문 eKOSPI는 장외에 선물 기반 환산
지수이므로 사이드바의 KOSPI 현물 지수와 값·비교 기준이 다를 수 있다.

## 장애 감지와 복구

- 국내·해외 지수는 네이버 JSON 실패 시 Yahoo로 자동 전환하며 `대체` 표시와
  공급원·기준 시각을 남긴다. 환율은 은행 고시·통화 단위가 다른 자료로 대체하지 않는다.
- 웹 서버의 감시 작업은 화면이 열려 있지 않아도 60초 간격으로 지표 18개를 확인한다.
  HTTP 성공 여부뿐 아니라 빈 값, `_stale`, 대체 공급원 사용, 거래 중 시세의 기준 시각을 검사한다.
  제공 지연 시간에 30분을 더한 허용 범위를 쓰며 장 마감·휴장 상태에는 장중 기준을 적용하지 않는다.
- 장애가 10분 이상 지속되면 관리자의 활성·인증된 알림 채널로 한 번 알리고,
  정상 복구 시 한 번 더 알린다. 발송 실패는 다음 점검에서 재시도한다.
  장애 시작·발송 상태는 SQLite 캐시에 보존해 웹 서버 재시작으로 중복 발송하지 않는다.
- 상태 변화는 `system_events`에 남고 기존 데이터 품질 점검·관리자 화면에도 포함된다.
  감시 결과가 5분 이상 갱신되지 않아도 정상으로 표시하지 않는다.
