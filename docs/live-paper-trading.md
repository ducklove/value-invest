# 장중 호가 기반 가상 운용

2026-09-17 · `live-book-pair-fok-v1`

## 실행과 범위

`/quant`의 시장 감시 계좌를 설정하고 **가상 운용 시작·재개**를 누른다. 시뮬레이션은
systemd 서비스의 작업자가 실행하므로 브라우저를 닫아도 거래일 09:00~15:20에 계속된다.
장외·휴장일에는 대기하고, 다음 장에 자동 재개한다. 신규 설치 시 다른 사용자의 가상
원장을 자동 생성하지 않는다. 사용자별로 명시적으로 시작한 원장만 실행한다.

가상자금 기본값은 1억 원이며 NH 모의 계좌 예수금과 무관하다. 실제 시장 시세는 나무
운영 시세 API에서 가져오지만, 가상 체결은 이 서비스의 별도 원장에 기록한다.
NH 모의 주문 서버나 실계좌 주문 서버에 주문하지 않는다.

종목별 근월물 순회 → 순우위 후보의 실시간 호가 감시 구조와 기존 호출 한도를 유지한다.
순회 목표는 기존 설정(현재 60분)이다. 전체 291개를 동시에 실시간 구독하는 방식이 아니며,
비구독 구간의 기회는 놓칠 수 있다. 보유 가상 포지션의 호가 구독을 후보보다 우선한다.
집중감시·보유 계약은 REST 계약·시장 상태를 약 60초마다 재검사하며 공유 호출 제한에 따라
지연될 수 있다. 마지막 성공 검증이 180초를 넘으면 가상 체결도 보류한다.

## 체결 모형

| 단계 | 현물 | 선물 |
|---|---|---|
| 진입 | 최우선 매도호가(ask)에 매수 | 최우선 매수호가(bid)에 매도 |
| 청산·평가 | 최우선 매수호가(bid)에 매도 | 최우선 매도호가(ask)에 매수 |

현재가·종가·호가 중간값을 체결가로 사용하지 않는다. 체결 근거로 양쪽 호가·거래소 시각·
수신 시각, 판단 시각, 적용 비용, 모형 버전을 함께 보관한다.

1. 양쪽 호가는 5초 이내, 시각 차이는 2초 이내여야 한다.
2. 진입 시 기존 순우위 기준(현재 50bp)을 넘으면 대기 주문을 생성한다.
3. 최소 1초가 지난 뒤 **양쪽 거래소 호가 시각이 모두 갱신**되고 조건도 유지돼야 체결한다.
   10초 내 확인하지 못하거나 조건이 사라지면 취소한다. 재연결은 새 양쪽 호가를 기다린다.
4. 수량은 최우선 잔량의 25%, 종목당 초기자금 10%, 가용자금, 최대 5종목 중 가장 제한적인
   값으로 정한다. 현물 잔량은 주수, 선물 잔량은 계약수로 환산한다. 선물 1계약은 현물 10주다.
5. [KRX 표준 주식선물 규칙](https://www.krx.co.kr/contents/OPN/01/01040401/OPN01040401T1.jsp)과
   나무 계약 표시명의 거래승수 10을 확인한 계약만 지원한다. 조정승수·연결이 불명확하면 보류한다.
6. 양쪽을 충족한 수량에 대해 **동시 가상 체결을 가정**한다. 청산 잔량이 보유량보다 적으면
   해당 수량만 청산하고 잔여량을 계속 보유한다. 같은 호가로 잔여량을 반복 체결하지 않는다.

이 모형은 실제 주문 경쟁, 시장 충격, 한쪽만 체결되는 위험을 재현하지 않는다. 실제 브로커
체결 성과와 구분하며, 이 원장만으로 실주문을 활성화하지 않는다.

## 비용·청산·자금

- 국내 현물 편도 0.01%, 선물 편도 0.006%. 실제 진입·청산의 각 거래대금에 적용한다.
- 매도세는 현물 매도금액의 20bp, 슬리피지는 양쪽 각 체결금액의 2bp를 기본 가정한다.
  슬리피지는 실제 관측 호가에 별도 비용으로 더하므로 체결 호가 자체를 가공하지 않는다.
- 금융비용은 현물 매입금액과 선물 증거금 가정액(20%)에 연 4%를 실제 보유 초 단위로 계산한다.
  배당 수입은 0원이다. 세금·증거금·금융비용은 감시 설정의 가정이며 브로커 확정 내역이 아니다.
- 새 진입에는 현물 매입금액·가정 증거금·진입 비용을 유보한다. 미실현 평가손실도 가용자금에서
  추가 공제한다. 증거금 일일 정산·추가 증거금의 정확한 브로커 모형은 지원하지 않는다.
  기존 포지션의 호가 평가가 5초를 넘기거나 검증이 중단되면 신규 자금 배분도 보류한다.
- 청산은 반대쪽 호가 기준 베이시스 10bp 이하, 비용 후 손실이 현물 진입금액의 100bp 이상,
  또는 최종거래일 2거래일 전 도달 시 실행한다. 청산도 새 양쪽 호가·잔량 조건을 충족해야 한다.
- 월물 전환일에는 구월물의 양쪽 포지션 청산을 우선한다. 구월물을 보유하는 동안 같은 현물의
  차월물 진입을 막는다. 청산 후 차월물은 진입 조건을 새로 확인한다. 양쪽 재진입 비용도 차감한다.
- 만기 이후에도 청산하지 못했다면 임의 결제가를 생성하지 않는다. 미청산·평가 보류 상태를
  유지하고 확인 대상으로 표시한다. 주식 권리조정·배당을 임의 수익으로 반영하지 않는다.

## 원장과 표시

`quant_paper_accounts`는 사용자별 포지션·자금·대기 주문 상태,
`quant_paper_events`는 대기·취소·가상 체결 근거를 저장한다. 체결 원장은 자동 삭제하지 않는다.
화면에는 최근 60개 판단을 표시한다. 원장 재개는 기존 초기자금·계좌·설정을 그대로 사용한다.
시작 버튼 재시도·서비스 재시작으로 가상자금이나 성과를 초기화하지 않는다.

청산호가 평가손익은 양쪽을 청산할 때의 비용까지 차감한 추정치다. 시세가 오래되거나 거래를
검증하지 못하면 마지막 평가 시각과 보류 상태를 표시한다. 장외에 과거 호가를 현재 체결로 만들지
않으며, 조건 미충족·시장 데이터 부재는 거래 0건으로 남긴다.

신규 가상 진입 중지는 기존 포지션의 청산 감시는 유지한다. 시장 감시 자체를 중지하면
호가 수집·가상 체결도 중지한다. 구 설정의 작업자는 generation 검사로 쓰기를 차단한다.

`GET /api/quant/paper`, `POST /api/quant/paper/start`, `POST /api/quant/paper/pause`는
로그인 사용자 원장에만 접근한다. 가상 운용 상태는 기존 `/api/quant/scanner`에도 포함된다.

기존 finance-pi 합성 경로 보고서는 변경하지 않는다. 이 원장은 실시간 관측에 대한 별도
전진 시뮬레이션이며, 저장하지 않은 전체 시장의 과거 틱을 재생한 백테스트가 아니다.
