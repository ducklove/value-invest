# 경제 캘린더 조건 알림

경제 캘린더의 **알림 조건**에서 국가별로 `전체`, `중 이상`, `상`을 선택하고 저장한다.
예: 한국 전체 / 미국 중 이상 / 일본 상. 국가를 삭제한 뒤 저장하면 해당 조건을 끈다.
알림 채널은 기존 텔레그램·카카오톡 설정을 공유한다.

- 화면의 표시 필터와 별도로 사용자 계정에 저장된다.
- 서버가 10분마다 조건에 맞는 일정을 자동 구독하므로 브라우저를 열어둘 필요가 없다.
- 설정 이후의 일정부터 적용한다. 새 조건 저장 전에 예정됐던 발표 결과는 소급 발송하지 않는다.
- 결과가 발표되면 한 번만 발송한다. 같은 일정의 개별 구독과 조건 구독은 중복 발송하지 않는다.
- 조건으로 구독하는 행에는 `🔔 조건`을 표시한다. 조건 밖 일정은 기존 체크박스로 개별 구독한다.
- 조건을 좁히거나 삭제하면 더 이상 맞지 않는 자동 대기 구독만 취소한다. 개별 구독과 발송 이력은 유지한다.

`GET/PUT /api/notifications/calendar/rules`가 설정을 읽고 저장한다. PUT은 전체 목록 교체이며
`{"rules":[{"country":"kr","min_importance":"all"},{"country":"us","min_importance":"mid"}]}` 형식이다.
국가 코드는 경제 캘린더 피드의 지원 목록을 사용하고 한 국가당 하나의 조건만 허용한다.

조건은 `economic_calendar_alert_rules`, 발송 대기는 기존 `economic_calendar_subscriptions`에
저장한다. `automatic` 컬럼으로 개별 구독과 구분하고 `(google_sub, event_id)` 고유 키로
중복을 막는다. 같은 조건을 다시 저장해도 적용 시작 시각을 유지하며, 조건을 바꾸면 시작 시각을 갱신한다.
피드는 최근 30일 이내 적용 시작일부터 앞으로 7일까지 공유 조회한다. 발송 실패 시 대기를 유지해 재시도한다.
동시에 실행되는 평가 작업은 프로세스 내 잠금으로 중복을 방지한다.
