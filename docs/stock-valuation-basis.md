# 종목 분석의 현재 PER / PBR

현재 지표 카드는 과거 연간 차트와 별도로 재무자료를 조회하고 현재가로 계산한다.
분모만 캐시하므로 실시간 시세가 바뀌면 배수도 다시 계산된다.

| 카드 | 계산 | 기간 |
| --- | --- | --- |
| PER | 현재가 / EPS 합계 | 가장 최근 확정 실적 4개 분기 |
| PBR | 현재가 / BPS | 가장 최근 확정 분기말 한 시점 |
| Forward PER | 현재가 / 예상 EPS | 리포트에 명시된 예상 회계연도 |
| Forward PBR | 현재가 / 예상 BPS | 리포트에 명시된 예상 회계연도 말 |

현재 실적은 NAVER Finance 분기 재무표의 확정 실적(`isConsensus=N`)을 사용한다.
EPS는 분기별 값을 합산하며, 4개 분기가 연속되지 않거나 하나라도 없으면
PER를 N/A로 표시한다. 손실 및 0인 분기도 합계에 포함한다. 최종 합계가 0 이하이면
PER 배수는 표시하지 않는다. BPS는 합산하지 않고 최신 분기 값 하나를 쓴다.
분기말과 실제 조회 시각을 반환하며, 제공되지 않는 연결/별도 구분과 공시일을
추정하여 채우지 않는다. 해당 제공사 자료는 현재 조회용이며 과거 시점 백테스트에
사용할 수 없다.

예상 실적은 최근 180일 이내 증권사 리포트 최대 3건 중 명시적인 연간 예상
EPS/BPS 표를 해석할 수 있는 가장 최신 리포트 한 건을 사용한다. 추정 표시가
있는 당해 연도 또는 다음 연도 열만 인정한다. 목표가의 적용 배수나 보고서 작성
당시 주가로 EPS/BPS를 역산하지 않는다. 통화가 원인 주당 지표만 사용하고
자료가 불명확하면 해당 forward 카드를 생략한다. 미래 12개월(NTM) 추정치가
아니므로 예상 회계연도를 카드에 표시한다. 출처 링크와 네이버 리포트 게시일도
제공한다. 여러 증권사의 컨센서스 평균은 아니다.

조회 경로는 `/api/analyze/{stock_code}/valuation`과
`/api/analyze/{stock_code}/forward-valuation`이다. 연간 분석 스냅샷에 현재 지표를
섞어 저장하지 않고 별도 캐시를 사용한다. 현재 실적은 1시간, 리포트 예상치는
24시간 캐시한다. 조회 실패나 미지원 종목은 이전 연간 값으로 대체하지 않는다.

과거 일간/주간 차트의 PER, PBR, EPS 등은 기존 연간 재무자료에 기반한 시계열로
유지하며 차트 설명에 그 기준을 명시한다. ROE 카드도 연간 실적이라고 표시한다.
포트폴리오 목표가 계산, 스크리너 등 다른 기능의 계산 계약은 이 변경의 대상이 아니다.
