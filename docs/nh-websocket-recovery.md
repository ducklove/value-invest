# NH 실시간 연결 복구

2026-10-07 운영에서 유효한 토큰으로 REST 조회는 성공했지만, 앱을 정지하고
공식 SDK로 단독 연결해도 `WSS10015`(앱키별 세션 수 초과)가 발생했다.
다른 프로세스와 컨테이너의 NH 연결은 없었다. NH 서버에 남은 세션을
`POST /websocket/close/session`으로 해제한 직후 등록 승인과 실제 시세 수신이
성공했고, 서비스에서도 국내 시세 24건의 승인과 수신을 확인했다.

NH 공식 Q&A는 비정상 종료 시 잔류 세션이 생길 수 있으며 이 API로 해제할 수
있다고 안내한다. 토큰 갱신이나 새 소켓의 구독 해제 요청은 잔류 세션을 해제하지 않는다.

## 서비스 처리

국내·해외·감시 연결은 키마다 소켓 2개와 초당 요청 10건 예산을 공유한다.
등록은 소켓당 최대 30건이며 통보 구독도 이 수에 포함된다. 종료 시 구독을
반납하고 소켓을 닫는다.

`WSS10015`가 발생하면 실패한 소켓을 닫고, **이 서비스에서만 사용한다고 확인한
키**에 한해 나머지 로컬 소켓도 닫은 뒤 공식 API로 잔류 세션을 해제한다.
복구 중 새 연결은 대기한다. 세대 번호와 60초 간격으로 중복 해제를 막는다.
토큰은 기존 캐시를 사용하고 REST의 키별 전송 간격도 지킨다.
`00000`은 해제 성공, 운영에서 확인한 `10000`은 이미 세션이 없는 상태다.

전용 키 여부는 암호화된 자격증명의 `ws_session_management`에 보관하며 기본값은
비활성이다. 현재처럼 연결된 NH 키가 정확히 하나이고 전용 사용이 확인된 환경에서는
진단 워크플로의 `manage_sessions=true`로 활성화할 수 있다. 여러 키가 있는 환경에서
이 옵션은 중단하며, 소유자 확인 후 키를 지정해 설정해야 한다.

## 해외 구독의 별도 오류

SDK 요약은 해외 구독 키를 GIC라고 설명하지만 포털 RC의 **요청** 명세는 티커
`AAPL`, **응답** 명세는 GIC `USAAAPL`이다. 운영 시험에서도 GIC와 공백으로 채운
GIC는 `WSS10012`(유효하지 않은 종목 코드), 티커는 `WSS10013`(유료 실시간 시세 등록
필요)을 반환했다. 요청에는 종목마스터의 원래 티커를 보내고 ACK·시세 식별에는
GIC를 함께 사용한다. 국내 연결을 유지하면서 해외 이용 신청 상태를 별도로 표시하고
기존 보조 시세 경로를 사용한다. 해외 권한 오류에는 전체 세션 해제를 수행하지 않는다.

포털은 유료시세 약정 후 토큰 재발급도 필요하다고 안내한다. 해외 보유 종목 전체의
별도 검사에서는 13건이 이용 신청 오류, 호주·독일·베트남 각 1건은 종목 코드 오류였다.
후자의 3건은 원래 티커·GIC·시장 접미사가 있는 티커를 모두 거절했다.
종목마스터에는 존재하지만 현재 NH 실시간 서버가 이 요청을 받아들이지 않는 상태다.
이 사실만으로 해당 국가 전체가 미지원이라고 단정하지 않는다. 동시에 발생하는
여러 오류 코드를 보존해 이용 신청 안내와 일부 종목의 구독 거절을 함께 표시한다.
